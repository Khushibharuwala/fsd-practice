# Skill Connect - Freelancing + LinkedIn Hybrid Platform

A full-stack web application that combines freelancing marketplace features with professional networking capabilities.

## Project Overview

Skill Connect is a platform where professionals can showcase their skills, experience, and services - similar to a combination of LinkedIn profiles and Fiverr/Upwork freelancing capabilities.

### Features
- 👤 Professional Profiles with Skills & Experience
- 💼 Service/Gig Listings
- 🔍 Search & Filter by Skills
- ⭐ Rating & Reviews System
- 💬 Messaging System
- 💳 Payment Processing
- 📊 Dashboard & Analytics

## Tech Stack
- **Frontend:** React.js, Tailwind CSS, Redux
- **Backend:** Node.js, Express.js
- **Database:** MongoDB
- **Authentication:** JWT, OAuth (LinkedIn)
